# CloudHerderNZ Architecture

**Date:** 2026-02-20
**Feature:** Comment System UI & API Integration

## Overview
The comment system will be a modular component that integrates with the existing Laravel 12 backend, Livewire 4 for reactivity, and Flux UI Free components for consistent styling. It supports nested replies, moderation, and user notifications.

## High‑Level Architecture
```
+-------------------+          +------------------+
|   Frontend (Blade) |<------->|  Livewire 4      |
+-------------------+          +--------^---------+
                                   |  Flux UI Components
                                   v
                          +---------------------+
                          |   API Endpoints     |
                          +----------^----------+
                                     |
                          +---------------------+
                          |   Eloquent Models    |
                          +---------------------+
```
- **Blade** renders the comment list and moderation panel using Flux UI components.
- **Livewire 4** handles real‑time updates, form submissions, and nested reply logic.
- **API** endpoints provide data for the user dashboard notifications.
- **Models/Relations**: `Post`, `Comment`, `User` with polymorphic relationships for replies.

## Detailed Design
### Database Schema
```php
Schema::create('comments', function (Blueprint $table) {
    $table->id();
    $table->foreignId('post_id')->constrained()->cascadeOnDelete();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->text('body');
    $table->boolean('approved')->default(false);
    $table->unsignedBigInteger('parent_id')->nullable(); // for nested replies
    $table->timestamps();
});
```
- `parent_id` allows unlimited nesting.
- Indexes on `post_id`, `user_id`, and `approved` for efficient queries.

### Models
| Model | Key Methods / Relationships |
|-------|----------------------------|
| Comment | `public function post(): BelongsTo`<br>`public function user(): BelongsTo`<br>`public function parent(): BelongsTo`<br>`public function replies(): HasMany` |
| Post | `public function comments(): HasMany` (with eager loading of approved comments) |

### Livewire Components
1. **CommentList** – Displays top‑level approved comments for a post.
2. **CommentItem** – Recursive component rendering a single comment and its replies.
3. **ReplyForm** – Inline form to submit a reply (visible only to authenticated users).
4. **ModerationPanel** – Admin view with approve/delete actions.

All components use Flux UI `<flux:card>`, `<flux:textarea>`, `<flux:button>` etc. for styling.

### Routes
```php
Route::middleware(['auth'])->group(function () {
    Route::get('/posts/{post}/comments', [CommentList::class, 'render']);
    Route::post('/comments/{comment}/reply', [ReplyForm::class, 'submit']);
});

// Admin moderation routes
Route::middleware(['auth', 'can:admin'])->prefix('admin')->group(function () {
    Route::patch('/comments/{comment}/approve', [ModerationPanel::class, 'approve']);
    Route::delete('/comments/{comment}', [ModerationPanel::class, 'destroy']);
});

// API for notifications
Route::middleware(['auth:sanctum'])->get('/api/notifications/comments', [CommentNotificationController::class, 'index']);
```

### Tests
- **Feature tests** for comment creation, reply nesting, approval workflow.
- **Livewire tests** using `livewire()` helper to assert component state changes.
- **API tests** ensuring authenticated users receive pending comments notifications.

## Edge Cases & Validation
- Prevent circular parent references.
- Rate limit replies per user per minute (via middleware).
- Soft deletes for moderation history.
- CSRF protection via Livewire’s built‑in guard.
